# Instrucciones de desarrollo

- No uses acentos invertidos en reportes de Word ni en archivos Markdown entregados.
- Usa D:\DevResources como raíz de recursos, cachés y temporales de desarrollo.
- Reutiliza los SDK y dependencias existentes.
- Guarda las cachés compartibles en D:\DevResources\Shared.
- Crea temporales separados por proyecto y ejecución en D:\DevResources\Sessions.
- Configura TEMP y TMP únicamente para cada sesión.
- Usa los lanzadores y bloqueos existentes.
- Ejecuta como máximo dos compilaciones pesadas simultáneas.
- Aplica exclusión entre tareas que escriban el mismo workspace.
- No cierres otros programas.
- No dupliques recursos en C: ni en otros discos.
- Conserva código, datos, autenticación y enlaces de compatibilidad.
- Limpia únicamente archivos regenerables e inactivos después de verificar sus referencias.
- No modifiques DriveFS.
